Back Homelab

A running log of my self-hosting journey

The Beginning

It all started when my brother began a networking class. I'd hear him talk about data privacy — how big companies were farming us for information. The idea grew on me that maybe I should do something about it. I started small, with my Raspberry Pi.

Timeline

Past

The Spark

I'd been aware of Raspberry Pis for a while, but only recently pulled the trigger. The appeal: a low-stakes playground. With a background in computer and data science, having a home environment to experiment with automation and new ideas — with no uptime requirements or breach consequences — was exactly what I wanted.

Present

Pi-hole + Recursive DNS

Set up Docker and Pi-hole, then configured a recursive DNS cache using Unbound. There was a learning curve — I initially installed Unbound natively instead of containerizing it, which made bridging with Docker more complex. Eventually containerized everything, enabling cleaner automation via cronjob scheduling (gravity list + container updates at 4am daily).

Present

Tailscale + Remote Access

Successfully set up Tailscale as a temporary VPN solution (WireGuard is next). Configured my Pi's tailnet IP as a global DNS server so any device on the network benefits from Pi-hole ad blocking. Now streaming video remotely through Jellyfin. With remote access established, the possibilities have expanded significantly.

Deprecated

Pi NAS Plan

Originally planned to build a Raspberry Pi NAS using three 4TB WD Red Plus HDDs, a penta SATA hat, and a 3D-printed case with hot-swappable drive bays and RAID 5. Thermal concerns — the Pi runs hot and heat kills HDDs — combined with needing to support up to 10 active users led me to rethink the approach entirely.

Present

Dell PowerEdge T320

Transitioning to the Dell PowerEdge T320 was a major leap. Moving off the Pi finally gave me the PCIe lanes and ECC RAM needed for a stable ZFS pool and multiple heavy Docker containers without hitting a hardware ceiling. Upgraded with an Intel Xeon E5-2470 V2 (10 cores / 20 threads, 2.4GHz) and 48GB DDR3 RAM. With that headroom, the server now handles Jellyfin media streaming and game servers for friends simultaneously — with room to grow.

Present

Cockpit + Linux LTS

Managing the T320 via Cockpit running on Linux LTS. It provides a web GUI for tasks that would take longer at the command line, though I still spend plenty of time in the CLI — writing Docker container configs, shell scripts, and automation. Goal is full service independence from subscription services, and the groundwork for self-hosted cloud storage is already in place.

Future

What's Next

Documenting the T320 build right here. Planning to upgrade home network security, turn my old house into a smart home, and achieve full independence from subscription services. WireGuard VPN is up next. I'll be sharing every triumph and challenge along the way.
